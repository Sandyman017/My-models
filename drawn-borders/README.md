# Drawn Borders

Draw your own country on a new world, then lead it season by season against rival nations.

**To play on Windows:** open the **Releases** page of this repository, download `Drawn-Borders-Setup-….exe` and run it. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

**To play in the browser:** download `drawn-borders.html` and double-click it (Chrome or Edge). Nothing to install.

The game is made from the files in `src/`. `node build.js` joins them into `drawn-borders.html`. See `CLAUDE.md` for how the code is organised and `game-plan.md` for the full history.
